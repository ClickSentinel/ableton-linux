# Wine patch base and provenance

Base repository: https://github.com/giang17/wine.git
Branch: `d2d1-dcomp-11.11`
Base commit: `7ea0c8b7dd`, `d2d1-dcomp stack: port to wine-11.11`

The current Wine series contains 43 files, numbered 0001 through 0045. Patches
0027 and 0044 are intentionally absent.

## Applying the series

Run `./build.sh`. Inside the Podman image, `scripts/container-build.sh`
unpacks `vendor/wine-base-7ea0c8b7.tar.zst`, creates a Git repository, and
applies `patches/00*.patch` in lexical order with `git am --3way`.

Some early patch files have no `From` or `Date` header. The build script adds a
fixed identity and date before passing those files to `git am`. A bare
`git am patches/00*.patch` command does not reproduce this step.

Patches 0008 through 0013 contain title-bar experiments and their reverts.
Apply them in sequence with the rest of the series.

## Provenance

- `0001`: redraw fixes from
  `sashaduke/ableton-live12-linux`, known good on 2026-06-30.
- `0002-0003`: winex11 changes from nine7nine/wine-nspa-src commits
  `a63120d350`, `ec6cc844f0`, and `7e15021e3f`. Patch 0003 also corrects the
  winex11 atom enum and name-table order.
- `0004-0026`: local GNOME and Mutter frame, reentrancy, plugin-window,
  DirectComposition, shared-session, sRGB, audio-name, and OpenGL fixes.
- `0027`: Git housekeeping. Its commit remains in the source history, but the
  patch file was removed from the shipped series on 2026-07-14.
- `0028`: resubscribe to Wine ALSA MIDI devices after reconnect. See
  `notes/ABLETON-WINE-MIDI-HOTPLUG.md`.
- `0029`: add 4 px to the Win32 menu-bar band at 96 DPI. This fixes the
  main-window resize offset at 100% scale. See
  `notes/ABLETON-WINE-DPI-SCALE-100.md`.
- `0030`: block stale-size DirectComposition blits. This is a partial Learn
  View fix. See `notes/ABLETON-WINE-LEARNVIEW-FLICKER.md`.
- `0031`: add the XDG file-dialog portal backend. It combines Wine MR !10060
  v5 patches 0001, 0002, 0003, and 0005 with its responsiveness follow-up,
  rebased from Wine 11.0 to this Wine 11.11 tree. MR patch 0004 was test-only
  and was not included. See `notes/ABLETON-WINE-FILE-PORTAL.md`.
- `0032`: add an x86-64 helper-scoped host libusb bridge for the Push 2
  display. It exports the 16-function Win64 libusb 1.0.23 ABI used by
  `Push2DisplayProcess.exe`. The i386 bridge is disabled. See
  `notes/ABLETON-WINE-PUSH2-DISPLAY.md`.
- `0033`: add `WINE_DISABLE_UNIX_MOUNT_REPARSE`. The launchers set it to `1`
  so Unix mount boundaries appear as normal directories instead of incomplete
  mount-point reparse records.
- `0034`: flush each XdndStatus reply. This prevents a queued XdndLeave from
  overtaking drop acceptance during fast drags from file managers under
  XWayland.
- `0035`: identify Intel Battlemage G21 GPUs, including Arc B580 device
  `0xe20b`. Without the entry, Wine reports the device as Intel HD Graphics
  4000, which Live 12 rejects for D3D11.
- `0036`: suspend DirectComposition reblits when the d2d1 device is null.
  This prevents a 200 ms timer loop when the graphics stack cannot create the
  device. See issue 16.
- `0037`: always advertise `MWM_FUNC_CLOSE`. KWin otherwise removes Live's
  close button while its startup modal disables the main window. Wine still
  ignores close requests while that window is disabled. Mailbox commit:
  `a080cbd2`.
- `0038`: keep menu tracking active while X input focus stays inside the same
  client. This prevents dropdowns from closing during focus changes under
  Mutter and Muffin. See `notes/ABLETON-WINE-MENU-FOCUSOUT.md`.
- `0039`: do not change a mapped popup from unmanaged to managed. The window
  manager makes that decision again on the next map. This prevents dropdown
  remaps and lost clicks. See `notes/ABLETON-WINE-DROPDOWN-MANAGED-FLIP.md`.
- `0040`: scale the menu-bar band with DPI. It corrects one-shot geometry for
  programmatic window-manager tiles at 125%. It did not stop the interactive
  resize loop, which patch 0042 fixes. Mailbox commit: `1173c1d5`. See
  `notes/ABLETON-WINE-DPI-SCALE-100.md`.
- `0041`: make DirectComposition presents visible on WebView2 layered targets,
  retry stale resize blits on a 120 ms timer for up to five attempts, and keep
  reblits active after idle. Mailbox commit: `9d34f87f`. See
  `notes/ABLETON-WINE-LEARNVIEW-FLICKER.md`.
- `0042`: treat sub-scale window-manager geometry differences as compositor
  rounding instead of returning them to Win32. This stopped Live's 2 px
  interactive resize loop on the tested 125% GNOME/XWayland setup. Adapted
  from ENCORE. Mailbox commit: `a014d2aa`. See
  `FINDINGS-RESIZE-GROWTH-2026-07-21.md`.
- `0043`: send Live's Show in Explorer request through the XDG OpenDirectory
  portal. Wine Explorer remains the fallback when the portal or policy refuses
  the request. Mailbox commit: `996524ab`. See
  `notes/ABLETON-WINE-SHOW-IN-EXPLORER.md`.
- `0044`: reserved for the issue 57 parked-pane reblit work. No patch file is
  shipped.
- `0045`: reject `RevokeDragDrop` for a window owned by another process. This
  prevents a foreign-process drop-target pointer from crashing Live when a
  WebView2 plugin editor closes. Ported from `giang17/wine` commit
  `fafb443f85e0`. See
  `notes/ABLETON-WINE-WEBVIEW2-PLUGIN-CLOSE-CRASH.md`.
